# Security policy

Do not report security vulnerabilities in public issues. Contact the
maintainers privately with a description, reproduction steps, and impact.

Never publish Supabase service-role keys, Clerk secret keys, webhook secrets,
database connection strings, encryption keys, real receipts, or personal
financial data. Environment files are excluded from version control.

If a secret may have been exposed, rotate it immediately and remove the
exposure from repository history.
