# Financial Dashboard inspiration

Source: [Financial Dashboard Community](https://www.figma.com/design/ZjTXtVUUIpR37VdLbQ4uwC/Financial-Dashboard--Community-?node-id=1-12&t=BgxPCY37N7g4H1vT-1)

## What this reference shows

The supplied frame is a light personal-finance dashboard called Cloudcash. It uses a large rounded white workspace, a slim left navigation, a large “Weekly sumup” header, a central account summary, goal cards, outcome statistics, a transaction history table, and a new-transaction form.

## Main design language

- Large white canvas with very soft gray background
- Rounded outer workspace with generous spacing
- Slim left sidebar separated by a light vertical line
- Blue primary accent
- Small secondary accents such as yellow, orange, green, and red
- Large friendly headings
- Rounded cards with soft shadows
- Clear empty space between functional groups
- Light gray secondary text
- Data presented as approachable summaries rather than dense reports

## What works for Abi Manager

The strongest ideas to borrow are:

- A spacious, calm main workspace
- A single clear summary at the top
- Goals treated as visible first-class objects
- A readable transaction history table
- Progress bars for spending or fundraising progress
- Simple category and status colors
- A clear “add transaction” action

This direction is especially useful for students who may not be comfortable with finance software. The layout communicates the important information without looking like accounting software.

## What we should change

The reference is oriented toward one person managing personal money. Abi Manager is shared by a class and needs more transparency:

- Replace “Cards” with “Current funds” or “Available balance”
- Replace “Outcome statistics” with “Money out by category”
- Replace personal contacts with receipt owners or responsible people
- Replace the transfer form with “Add income” and “Add expense” actions
- Add receipt status directly to transaction rows
- Add who created or approved an entry
- Add the active school year or finance period
- Keep the goal cards, but add target date, owner, and amount remaining

## Recommended Abi Manager adaptation

### Page structure

Use this order for the first dashboard:

1. Page title and current period
2. Available balance summary
3. Income, expenses, and missing-receipt metrics
4. Active fundraising goal
5. Recent transaction history
6. Needs-attention panel

### Cards

Use cards sparingly. Recommended cards:

- Available balance
- Income this period
- Expenses this period
- Open receipts
- One active goal card

Avoid turning every small number into a card. The reference is visually attractive, but too many rounded surfaces would make Abi Manager feel decorative rather than trustworthy.

### Color system

Keep the base palette close to the current project:

- Canvas: warm white or very light gray
- Surface: white
- Text: near-black
- Muted text: medium gray
- Border: very light gray
- Accent: one calm blue or green
- Positive: muted green
- Attention: muted amber
- Expense: muted red

Do not use a different bright color for every dashboard card. Color should communicate status, not decoration.

## Avoid copying

- Personal credit-card details
- Fake transfer contacts
- Oversized rounded containers everywhere
- Decorative illustrations that do not help the finance workflow
- Rainbow-colored statistics
- Personal banking language

## Decision

Use this reference for Abi Manager’s spacious layout, approachable typography, goal progress, transaction history, and light visual tone. Combine it with Finebank’s stronger navigation and admin structure. The final design should be a simple class-finance workspace: light main content, a controlled sidebar, clear totals, visible goals, and transparent records.
